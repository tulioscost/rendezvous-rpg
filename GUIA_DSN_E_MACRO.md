# Instalação da atualização v0.8.4

1. Instale Foundry V13 com uma versão compatível de Dice So Nice! (o Dice So Nice! atual requer V14).
2. Instale RENDEZVOUS v0.8.4 pelo ZIP ou pelo manifesto publicado após a Release.
3. Reinicie o Foundry, crie um mundo RENDEZVOUS e confira Dice So Nice! ativo.
4. Configure Dice So Nice! → Dice Presets → **Solis**, **Vigília** ou **Ruptura**.
5. Teste uma rolagem de 1d6 em um herói e confira dados 3D em cena + mensagem com Ímpetos.
6. Como GM, instale a macro: `await game.rendezvous.installHeroMacro()` e execute-a da barra.
7. Verifique a ficha em cinco páginas, a imagem substituível, a geração de herói e as técnicas criadas.
8. Em caso de ausência do dado, veja F12 para problemas da API do Dice So Nice!.

A dependência é obrigatória no manifesto; em V13 instale edição antiga do módulo compatível com V13.
